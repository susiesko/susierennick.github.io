Beading Platform

Full-stack pattern designer for bead artists with inventory tracking and pattern PDF export.

About

A comprehensive web platform for bead artists. Features include a visual pattern designer for peyote stitch (rectangular and radial grids), personal bead inventory management, a public bead catalog with Miyuki data, and PDF pattern export.

Features

  • Visual pattern designer supporting multiple techniques:
    • Peyote stitch (rectangular)
    • Loom weaving (rectangular)
    • Peyote warped square (radial)
    • Peyote triangle (radial)
  • Personal bead inventory management with custom bead support
  • Public bead catalog with Miyuki product data
  • PDF pattern export for offline use and printing

Tech Stack

React TypeScript Node.js Express PostgreSQL Prisma Tailwind CSS Konva
